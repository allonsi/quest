# quest
Create your quests and rewards

현실을 살면서 우리는 많은 할일에 직면한다. 하지만 할일을 기록하는 것도 힘들고 할일을 해내더라도 우리는 명확한 보상을 받지 못하는 경우가 많다.

이 문제를 해결하기 위해 만든 앱 작성 프로젝트 Quest Maker! 우리 스스로 퀘스트와 보상을 작성하고 퀘스트를 깬 후 보상을 받자!

1. 퀘스트 생성 버튼을 눌러 퀘스트 작성 창을 만든다.

2. 퀘스트 작성 창에서 해야할 일을 기록한다. 같은 작성 창 안에 해야할 일이 연계가 된다면 하위/연계 퀘스트 작성도 가능하다. 각 하위/연계 퀘스트 작성 시 해당 퀘스트 창의 퀘스트 진행 상황도 표시된다.
    - 하위 퀘스트의 경우 순서 상관없는 경우. 다른 퀘스트 수행 여부 관계없이 체크박스가 항상 활성화.
    - 연계 퀘스트의 경우 순서가 상관있는 경우. 앞서 작성된 연계 퀘스트 수행이 안되면 체크박스가 활성화되지 않는다.

3. 퀘스트 작성 창에서 받고 싶은 보상도 기록한다. 보상은 해당 퀘스트의 진행 상황이 100%인 경우 보상을 받을 수 있도록 "보상 받기" 버튼이 생성된다.

4. 퀘스트 작성을 마치면 퀘스트가 저장된다. 저장된 퀘스트들은 퀘스트 모음에서 확인 가능하다.

5. 퀘스트 모음에는 탭이 세 가지가 있다.
    1) 작성 중: 아직 작성 중이거나 수정/편집 중인 퀘스트 모음
    2) 진행 중: 작성을 완료하고 저장된 퀘스트. 보상을 아직 받지 않은 퀘스트들. 진행 상황이 100%이지만 보상을 받지 않은 퀘스트도 포함
    3) 완료됨: 각 퀘스트의 진행상황을 모두 완료한 퀘스트들 중 보상을 받은 퀘스트 목록.

6. 퀘스트 모음을 열면 저장된 퀘스트들을 확인할 수 있으며 각 퀘스트를 누르면 작성된 퀘스트 상세 내용을 볼 수 있다. 진행 중인 퀘스트의 경우 체크박스를 체크 혹은 체크 해제 할 수 있으며 모든 연계 퀘스트의 체크박스가 체크된 경우 "보상 받기" 버튼이 활성화된다.

7. 나만의 NPC가 있으며 궁금한 사항이 있을 때 왼쪽 하단의 물음표 버튼을 누르면 NPC가 나와서 앱 기능에 대해 설명을 해줄 수 있다. 또한 퀘스트 작성 완료 시, 퀘스트 수행 완료 시, 보상 받기 완료 시에 칭찬하는 말을 해준다.

8. 보상의 경우 스스로 어떤 보상을 내렸는지 짧게 글로 기록하거나 사진을 추가하여 보상을 기록하게 한다. 보상 기록이 완료되면 보상 완료가 된다. 보상 받기 완료까지 되면 해당 퀘스트는 완료됨 탭으로 이동되어 저장된다.

## 웹 버전 실행

Mac에서는 Finder에서 **`Quest Maker.command`를 더블클릭**하면 서버와 브라우저가 자동으로 열린다.
사용 중에는 자동으로 열린 서버 창을 켜두고, 종료하려면 `Ctrl+C`를 누른다.

패키지 설치 없이 저장소 폴더에서 실행:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory web
```

브라우저에서 **http://127.0.0.1:4173/** 를 열면 된다. 퀘스트와 사진은 현재 브라우저에 저장된다.
자세한 실행 방법, 백업, PWA, 개발 안내는 [DEVELOPMENT.md](DEVELOPMENT.md)를 참고한다.

## 다른 기기로 기록 옮기기

**일지 설정 → 이메일로 로그인 · 가입**에서 계정을 만든 뒤, 다른 기기에서도 같은 계정으로 로그인하면 퀘스트와 보상 사진이 자동 동기화된다.
기존 기기 기록은 로그인 후 **이 기기 기록 가져오기**로 한 번 옮긴다.
로그인과 서버 설정 안내는 [SUPABASE.md](SUPABASE.md)를 참고한다.

로그인 없이 **일지 설정 → 백업 파일 저장**으로 글과 사진이 포함된 JSON 파일을 저장한다.
이 파일을 다른 기기로 옮긴 뒤 **일지 설정 → 백업 불러오기**로 가져온다.
백업 파일로 옮기는 경우에는 같은 ID의 퀘스트가 가져온 백업 내용으로 갱신된다.
